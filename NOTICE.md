# Code and Data Notice

This repository is a cleaned research workspace for experiments and paper
drafting around ranked LazyFCA pattern-structure hypotheses.

Some code was derived from earlier LazyFCA research code. Keep original
authorship, citation, and license information visible when known. Do not remove
attribution when moving code between repositories.

Dataset files are not tracked by default. Before publishing datasets in this
repository, check the redistribution terms for each source.

If external implementations of vanilla LazyFCA, randomized LazyFCA, or IPS-KNN
are copied into this repository, place them in a separate folder and include:

- source paper or repository;
- authors;
- license or permission status;
- date copied;
- local modifications.
