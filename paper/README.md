# Paper Draft Files

- `main.tex`: LaTeX draft of the paper structure and core technical story.
- `mybib.bib`: bibliography file.
- `gpt_deep_research_results.md`: collected external AI/literature-search
  notes.
- `context_for_ai_assistants.txt`: pasteable project context for other AI
  threads helping with references, related work, and writing.
- `my_other_papers/`: local author-owned PDF/LaTeX sources for the accepted
  FCALC/randomized FCALC/IPSKNN paper and the earlier IPS-KNN position paper.

Canonical planning files live in `docs/`:

- `docs/project_context.md`: full technical/research context.
- `docs/experiment_plan.md`: full experiment plan.
- `docs/paper_plan.md`: full paper-writing plan.

The draft intentionally contains TODO markers for references, final results,
and related-work expansion.

When using `my_other_papers/`, cite the accepted paper for the imported
FCALC/randomized FCALC/IPSKNN baselines and cite the position paper for the
initial IPS-KNN idea where needed. Rephrase all descriptions; do not copy
manuscript text verbatim into this paper.
